# 남강포장 로고 파일

| 파일 | 용도 |
|---|---|
| `namgang-logo-light.svg` | 주식회사 남강포장 · 흰 배경용 |
| `namgang-logo-dark.svg` | 주식회사 남강포장 · 어두운 배경용 |
| `namgangpack-logo-light.svg` | 영문 namgangpack · 흰 배경용 |
| `namgang-symbol.svg` | 심볼만 (프로필 사진, 파비콘 등) |

## 글자는 도형(아웃라인)으로 변환되어 있습니다

로고 안의 글자는 모두 도형(path)으로 바뀌어 있어서, 글꼴이 설치되지 않은 컴퓨터나 프로그램에서도 똑같이 보입니다. 파일 안에 글꼴 데이터는 들어 있지 않습니다.

## 사용한 글꼴과 라이선스

| 글꼴 | 사용 부분 | 라이선스 |
|---|---|---|
| Pretendard SemiBold | 한글 "주식회사 남강포장" | SIL Open Font License 1.1 |
| Montserrat Medium | 영문 "namgangpack" | SIL Open Font License 1.1 |

두 글꼴 모두 SIL Open Font License 1.1로 배포되어, 상업적 사용과 로고 제작, 도형 변환이 허용됩니다.
(참고: https://openfontlicense.org)
