# 남강포장 홈페이지

경기도 안성 골판지 박스 제조업체 **주식회사 남강포장**의 홈페이지입니다.

## 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 메인 (원스톱 공정 슬라이드, 제품, 공정, 납품 사례, 친환경, FAQ, 빠른 견적) |
| `contact.html` | 견적문의 (3단계 폼, 사진 첨부, FAQ) |
| `css/style.css` | 공통 스타일 |
| `js/config.js` | 전화·팩스·이메일·카카오톡 채널 주소 설정 |
| `js/main.js` | 메뉴, 슬라이드, 스크롤 효과, 견적 전송(`submitQuote`) |
| `js/quote-form.js` | 견적문의 3단계 폼 |
| `images/CREDITS.md` | 데모 사진 출처 (Unsplash) |

## 연락처 바꾸기

`js/config.js`의 값을 수정하면 사이트 전체의 전화·이메일·카카오톡 버튼에 반영됩니다.

## 배포

GitHub Pages로 배포합니다. 저장소 Settings → Pages에서 `main` 브랜치의 루트(`/`)를 선택하세요.

## 아직 할 일

- 회사소개·제품소개·설비공정·채용·개인정보처리방침 페이지
- 카카오톡 채널 주소, 상담 시간, FAQ 답변
- 실제 공장 사진으로 교체
- Supabase 연결 (견적 접수 저장, 관리자 페이지)
