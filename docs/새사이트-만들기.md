# 이 사이트를 틀로 새 사이트 만들기

남강포장 홈페이지를 복사해 다른 회사 사이트를 만드는 순서입니다.
새 작업(새 대화)에서 이 파일을 열고 그대로 따라 하면 됩니다.

> **한 줄 요약:** 폴더를 복사하고 → 남강포장 전용 파일을 지우고 → 회사 정보·로고·문구·사진을 바꾸고 → 새 GitHub 저장소와 새 Supabase 프로젝트에 연결합니다.

---

## 0. 시작 전에 정할 것

| 항목 | 예시 | 비고 |
|---|---|---|
| 회사명 / 업종 | (주)○○○ / 금속 가공 | |
| 사이트 목적 | 견적 문의, 예약, 소개 | 견적 폼을 쓸지 결정 |
| 도메인 | ○○○.com | 없으면 `계정명.github.io/저장소명` 무료 주소 사용 |
| 견적 접수·관리자 페이지 | 필요 / 불필요 | 불필요하면 6·7단계 생략 |
| 로고 파일 | AI·PNG·JPG | 없으면 글자 로고로 제작 가능 |

## 1. 폴더 복사

`C:\바이브코딩작업\웹페이지test` 를 새 폴더로 복사합니다. (예: `C:\바이브코딩작업\새회사`)

**복사 후 반드시 지울 것** — 남강포장 전용입니다.

| 지울 것 | 안 지우면 생기는 일 |
|---|---|
| `.git` 폴더 | 남강포장 저장소로 커밋·푸시됨 |
| `CNAME` | 새 사이트가 www.namgangpack.com 으로 연결됨 |
| `googleb62fd0200a315334.html` | 남강포장 구글 소유확인 파일 |
| `naveref53662de653d260745cf9fa49891ed9.html` | 남강포장 네이버 소유확인 파일 |
| `CI_남강포장/`, `남강포장_CI.zip` | 남강포장 로고 묶음 |
| `사진원본/` (있다면) | 남강포장 사진 |

**Supabase 키는 반드시 교체** (지우지 말고 새 값으로 덮어쓰기)
`js/config.js` 의 `supabaseUrl`, `supabaseAnonKey` 를 그대로 두면 **새 회사 견적이 남강포장 문의함으로 들어갑니다.** 새 프로젝트를 만들기 전까지는 두 값을 빈 문자열(`''`)로 비워 두세요. 비어 있으면 견적 폼이 자동으로 메일 접수 방식으로 동작합니다.

## 3. 로고·색상 바꾸기

- 로고: `images/logo/` 교체. 헤더·푸터는 HTML 안에 인라인 SVG로 들어 있으니 같이 교체
- 파비콘: 각 HTML `<link rel="icon">` 의 data URI
- 색상: `css/style.css` 위쪽 `:root`
  - 크라프트 옐로 `#F2B233`, 골드 `#C78A12`, 차콜 `#1F1F1F`
  - 관리자 페이지 색은 `admin/admin.css` 의 `:root`
- 글꼴: 한글 Pretendard Variable, 영문 Montserrat (둘 다 무료 상업용). 바꾸려면 각 HTML의 글꼴 링크와 `--font-ko`, `--font-en`

## 4. 문구·사진 바꾸기

- 사진은 모두 Unsplash 무료 이미지이며 목록은 `images/CREDITS.md` 에 있습니다. 업종에 맞는 사진으로 교체하세요.
- 사진 자리 정의는 `js/slots.js` (34곳). 자리를 늘리거나 줄이면 이 파일도 함께 고칩니다.
- 업종이 다르면 제품·공정·FAQ 내용은 새로 써야 합니다.

## 5. GitHub 저장소 만들고 배포

1. GitHub에서 새 저장소 생성 (Public)
2. 새 폴더에서
   ```bash
   git init
   git add -A
   git commit -m "첫 배포"
   git branch -M main
   git remote add origin https://github.com/<계정>/<새저장소>.git
   git push -u origin main
   ```
3. 저장소 **Settings → Pages → Source: main / (root)**
4. 도메인이 있으면 `CNAME` 파일에 도메인 한 줄을 넣고, DNS에 A 레코드 4개(185.199.108~111.153)와 www CNAME(`<계정>.github.io`)을 설정

> 파일을 바꾸면 각 HTML의 `?v=날짜숫자` 캐시 버전을 올려야 방문자 화면에 바로 반영됩니다. (GitHub Pages는 약 10분 캐시)

## 6. Supabase (견적 접수·관리자 페이지를 쓸 때만)

1. 새 프로젝트 생성 — 지역 **Northeast Asia (Seoul)**, 무료 플랜은 조직당 2개까지
2. SQL Editor에서 `supabase/schema.sql` 전체 실행 (표·보안 규칙·저장소·알림 트리거까지 포함)
3. Authentication → **회원가입 끄기**
4. 첫 관리자 계정 생성 후 명단 등록
   ```sql
   insert into public.admin_users (email, role) values ('관리자@example.com', 'owner');
   ```
5. Project Settings → API 의 **Project URL**과 **anon key**를 `js/config.js` 에 입력
6. Edge Function 2개 배포 (대시보드 → Edge Functions → 편집기에 코드 붙여넣기)
   - `admin-users` : 관리자 페이지의 담당자 추가·삭제·비밀번호 재설정
   - `notify-quote` : 새 견적 알림 메일 — 코드 안의 `ADMIN_URL`, `FALLBACK_TO` 를 새 회사 값으로 수정
7. 알림 메일을 쓰려면 Edge Functions → Secrets 에 `RESEND_API_KEY` 등록 (Resend 무료 가입)

## 7. 검색 등록 (사이트 완성 후)

1. 각 HTML에 검색 차단(`noindex`)이 남아 있지 않은지 확인
2. `sitemap.xml`, `robots.txt` 의 주소를 새 도메인으로 수정
3. 구글 서치 콘솔 등록 → 확인 파일 업로드 → 사이트맵 제출
4. 네이버 서치어드바이저 등록 → 확인 파일 업로드 → 사이트맵 제출
5. 네이버 스마트플레이스 등록 (사업자 인증 필요, 지역 검색에 효과가 큼)

## 마무리 점검

- [ ] `CNAME`, 소유확인 파일이 새 회사 것으로 바뀌었는가
- [ ] `js/config.js` 의 Supabase 값이 새 프로젝트 것인가 (남강포장 값이 남아 있지 않은가)
- [ ] 견적 폼으로 테스트 접수 → 새 프로젝트 문의함에 들어오는가
- [ ] 알림 메일이 새 회사 담당자에게 오는가
- [ ] 휴대폰 화면에서 가로로 밀리는 곳이 없는가
- [ ] 개인정보처리방침의 회사명·보호책임자·보관기간이 맞는가
- [ ] 사업자등록번호·대표자·주소에 남강포장 정보가 남아 있지 않은가 (전체 검색으로 확인)
